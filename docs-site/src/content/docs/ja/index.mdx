## HAGISTACK とは

HAGISTACK は、Rocky Linux 10.2 に OpenStack 2026.1（Gazpacho）を導入する Bash スクリプトです。
Rocky Linux は OpenStack を同梱していないため、HAGISTACK は 2026.1 のリリース tarball からビルドした RPM を GitHub Releases で配布し、インストーラーがそれを取得・検証して使います。
導入先のホストで OpenStack の RPM をビルドする必要はありません。

  <Card title="All-in-one" icon="laptop">

  <Card title="Horizon" icon="seti:html">
    ブラウザから `http://管理IP/dashboard/` にログインし、イメージ・Flavor・ネットワーク・インスタンス・Floating IP を操作できます。
  </Card>
  <Card title="検証付きの RPM 取得" icon="approve-check">
    取得した RPM は、Git タグ内の lock に固定した SHA-256、サイズ、RPM セットの同一性で検証してから使います。
  </Card>

## 対応環境

| 項目 | 内容 |
|---|---|
| OS | Rocky Linux 10.2（ほかの EL10 は未検証） |
| アーキテクチャ | x86_64 のみ |
| 権限 | `sudo` による root |
| メモリ / ディスク | All-in-one で 8 GB 以上 / `/` に 20 GB 以上の空き |
| 構成 | All-in-one、Controller + Compute（検証済みは Compute 1 台まで） |

詳しい要件と制限は [インストール前の準備](/ja/quickstart/prepare/) と [既知の制限](/ja/operations/limitations/) を参照してください。

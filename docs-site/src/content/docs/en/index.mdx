## What HAGISTACK is

HAGISTACK is a Bash script that installs OpenStack 2026.1 (Gazpacho) on Rocky Linux 10.2.
Rocky Linux does not ship OpenStack. HAGISTACK builds the RPMs from the 2026.1 release tarballs and publishes them on GitHub Releases; the installer downloads and verifies them.
Nothing has to be built on the hosts you install.

## Supported environment

| Item | Value |
|---|---|
| OS | Rocky Linux 10.2 (other EL10 distributions are not verified) |
| Architecture | x86_64 only |
| Privileges | root through `sudo` |
| Memory / disk | 8 GB or more and 20 GB free on `/` for all-in-one |
| Configurations | all-in-one; controller + compute (verified with one compute node) |

See [Before you install](/en/quickstart/prepare/) and [Known limitations](/en/operations/limitations/) for the details.
